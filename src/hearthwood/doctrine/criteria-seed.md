# My criteria

How I judge a board. Every reading reads this file first, and what is written here outranks the
reading's own defaults. Write in plain sentences; one rule per line is easiest to keep.

`manager review` asks for a verdict on each finding and offers to turn your reasons into rules
here. You can also edit this file by hand at any time, or add a line with
`manager criteria add "..."`.
